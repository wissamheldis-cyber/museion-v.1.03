# Screenshots Sprint 1

Les captures d'écran sont prises manuellement depuis le navigateur ou via Playwright (Sprint 3).

## Routes à capturer

- `/login` — Page de connexion Museion
- `/` — Accueil (3 cartes espaces)
- `/cinema` — Dashboard Cinéma
- `/cinema/projects` — Liste des projets
- `/cinema/projects/new` — Nouveau projet (4 étapes)
- `/cinema/projects/gilgamesh` — Workspace Gilgamesh
- `/cinema/projects/gilgamesh/development` — Développement (7 onglets)

## Instructions

1. Ouvrir `http://localhost:3000`
2. Se connecter avec `administrateur`
3. Naviguer vers chaque route
4. Capturer avec l'outil de capture du navigateur (F12 → Device toolbar)
